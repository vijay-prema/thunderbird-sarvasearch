SarvaSearch Settings

Services

The index. Needs Qdrant 1.20 or newer (keyword search uses its BM25 text queries).
Changing the model changes the vector size: clear the index and rebuild.

Search

Hybrid fuses both engines by rank (Reciprocal Rank Fusion). The mode can also be switched on the search page.

Agent access

Must match the daemon's --port / --host.
If set, it must equal the daemon's --token. Any local process can otherwise ask Thunderbird to open a message — harmless, but noisy.

Indexing

How much of each email body is searchable. Changing this needs a rebuild.
The swatch is the colour the search results use for that account — the one Thunderbird shows when the bridge daemon can read your profile, a generated colour otherwise. Pick a colour to override it; “auto” goes back to Thunderbird's.
